Diagnostics
How it works, and why the answer isn’t unique

An autostereogram is built by taking a depth map Z and, for every pixel, forcing two pixels a distance s apart to be the same colour, where s(Z) = (1−µZ)·E/(2−µZ). Everything not pinned by a constraint is filled at random, and each scan line is done independently. So the image doesn’t store intensities that mean anything — it stores which pairs of pixels are tied together. Recovering the depth map means recovering that disparity field.

That inverse is genuinely ill-posed, in four separate ways:

  • Period aliasing. If the carrier repeats with period T, then d, d±T, d±2T all fit the data identically. This is the classic wallpaper problem.
  • Echoes. Constraints compose: if a=b and b=c then a=c — a match the generator never intended, corresponding to no surface at all. These are exactly consistent, so no better matching can remove them.
  • Untextured carrier. Where the pattern is locally flat, many disparities match equally well.
  • Half-occlusion. Hidden-surface removal deletes some constraints entirely, leaving pixels with no valid partner.

So there is no single right answer, and the question becomes which functional to minimise. This solver takes the MAP estimate, E(d) = Σ D(d) + λ Σ V(d, d′), with a census-transform data term D (invariant to shading, robust to JPEG, computed across all three colour channels) and a truncated-linear / total-variation prior V. The prior choice is what actually decides the answer: a quadratic penalty — the usual default — would round off the object silhouette, which is the entire signal. TV permits one sharp jump as cheaply as many small ones, so it prefers piecewise-smooth depth with crisp edges. Minimisation is by semi-global matching over 4 or 8 paths.

One detail specific to this problem is worth the emphasis: because scan lines are generated independently, matching noise is independent per row while the true depth is strongly correlated vertically. Weighting the vertical prior above the horizontal one is therefore a large, free win.

Depth is finally recovered metrically by inverting the separation function, Z = (E−2s)/(µ(E−s)), with E self-calibrated from the solution (the far plane is the largest separation). Absolute scale is still a gauge freedom: if the scene never reaches the near or far plane, no method can know where those planes were.

Everything runs locally: the image is decoded to a canvas, solved in a Web Worker (or on the main thread when opened directly from disk), and rendered back. No analytics, no fonts, no frameworks. The only network request it ever makes is fetching an image URL you explicitly ask for — typed or pasted into the URL field, or dropped onto the drop zone — and your image pixels are never sent anywhere.
